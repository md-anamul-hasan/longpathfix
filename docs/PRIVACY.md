# LongPathFix privacy policy

_Last updated: 2026-10-22_

LongPathFix runs entirely on your PC. It makes no network connections: no telemetry, no update check, nothing is uploaded. It reads file and folder names in the folder you scan, and when you rename it stores a log locally so renames can be undone.

There is no account, no licence key, no analytics and no crash reporting. Logs stay on your machine in `%APPDATA%\LongPathFix`.
